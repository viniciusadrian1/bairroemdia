# Assets da interface

Identidade visual do Bairro em Dia, direção Encontro.

- Logos e símbolo: SVG em contornos; o lettering é derivado de Fraunces Italic.
- `favicon.png`: variante simplificada para 32 px.
- `app-icon.png`: ícone para a navegação recolhida.
- `fraunces.woff2` e `bricolage.woff2`: conversão de formato dos TTF variáveis originais do kit, sem redesenho dos glifos. Licenças preservadas nos arquivos OFL.

Famílias de apoio: Fraunces e Bricolage Grotesque. O logotipo não deve ser reconstruído digitando a fonte.
