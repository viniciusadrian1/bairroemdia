# Recursos de execução

`corpus_texto.jsonl` contém trechos da base documental consultada pelo assistente. Os metadados de cada registro preservam a origem disponível no corpus. Não é uma base de ocorrências ou de gravações dos usuários. O assistente também consulta `backend/data/knowledge.json`, com referências públicas e regras locais do piloto.

`integrations.json` descreve os componentes da aplicação. Os estudos acadêmicos de Cluster e Computação Quântica são entregues separadamente e não são dependências de execução.
